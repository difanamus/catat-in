01

Tentang Aplikasi Catat-in

Catat-in adalah aplikasi pencatatan keuangan untuk Usaha Mikro Kecil dan Menengah (UMKM) yang dikembangkan secara independen. Aplikasi ini membantu pemilik usaha mencatat transaksi pemasukan dan pengeluaran, mengelola kategori, serta memantau arus kas usaha secara mudah dan efisien.

Kebijakan Privasi ini berlaku untuk aplikasi Android Catat-in (Package ID: com.umkm.app) dan menjelaskan bagaimana kami mengumpulkan, menggunakan, dan melindungi informasi Anda.

🛡️ Catat-in dirancang dengan prinsip offline-first — semua data Anda disimpan terlebih dahulu di perangkat Anda sendiri. Sinkronisasi ke cloud hanya dilakukan saat Anda online dan bertujuan untuk backup serta kolaborasi antar perangkat.

03

Izin Perangkat yang Diperlukan

Catat-in meminta izin berikut pada perangkat Anda. Setiap izin hanya digunakan untuk fungsi yang disebutkan:

📷
CAMERA

Digunakan untuk mengambil foto nota/struk transaksi sebagai bukti pengeluaran atau pemasukan. Kamera tidak diakses di latar belakang.

🌐
INTERNET

Digunakan untuk menyinkronkan data transaksi ke cloud (Supabase) saat perangkat terhubung ke internet. Aplikasi tetap berfungsi penuh tanpa koneksi internet.

🔔
POST_NOTIFICATIONS

Digunakan untuk mengirim pengingat pencatatan transaksi sesuai jadwal yang Anda atur (misalnya pengingat pagi dan malam).

☀️
RECEIVE_BOOT_COMPLETED

Digunakan agar jadwal notifikasi pengingat dapat dipulihkan otomatis setelah perangkat dinyalakan ulang (restart).

👆
USE_BIOMETRIC

Digunakan untuk otentikasi biometrik (sidik jari/wajah) sebagai alternatif PIN saat membuka aplikasi. Data biometrik tidak disimpan oleh aplikasi — diproses sepenuhnya oleh sistem Android.

🎙️
RECORD_AUDIO

Digunakan untuk fitur input suara (voice-to-text) saat mencatat transaksi. Rekaman audio tidak disimpan — hanya diproses secara lokal untuk konversi teks.

05

Penyimpanan & Sinkronisasi Data

Catat-in menggunakan arsitektur offline-first. Data selalu disimpan terlebih dahulu di penyimpanan lokal perangkat menggunakan database Room (SQLite). Sinkronisasi ke cloud dilakukan secara otomatis di latar belakang oleh WorkManager saat perangkat terhubung ke internet.

// Alur Penyimpanan Data
LapisanTeknologiData yang Disimpan
Lokal (Perangkat) Room Database (SQLite) Semua data transaksi, kategori, usaha, pengaturan, hash PIN
Cloud (Remote) Supabase (PostgreSQL) Transaksi, kategori, data usaha (tanpa PIN, tanpa biometrik)
Cloud Storage Supabase Storage Foto nota/struk transaksi

Server Supabase yang kami gunakan berlokasi di Singapore (Asia-Pacific). Data disimpan dengan enkripsi saat penyimpanan (encryption at rest) dan enkripsi saat transmisi (TLS/HTTPS).

Data lokal Anda tersimpan di penyimpanan internal aplikasi dan tidak dapat diakses oleh aplikasi lain. Sesuai konfigurasi manifest, fitur Android Backup (allowBackup) dinonaktifkan untuk melindungi privasi data usaha Anda.

Berbagi Data dengan Pihak Lain

✅ Kami tidak menjual, menyewakan, atau memperdagangkan data Anda kepada pihak ketiga manapun.

Data Anda hanya dapat dibagikan dalam situasi berikut:

// Kondisi Berbagi Data
KondisiPenjelasan
Kolaborasi Usaha Ketika Anda membagikan kode undangan usaha ke rekan kerja, mereka dapat mengakses data transaksi usaha yang sama. Ini adalah fitur yang Anda aktifkan secara sadar dan sukarela.
Penyedia Infrastruktur Supabase sebagai penyedia database cloud dapat mengakses data sesuai kebijakan privasi mereka. Kami menggunakan Supabase hanya sebagai penyimpanan data terenkripsi.
Kewajiban Hukum Jika diwajibkan oleh hukum yang berlaku di Indonesia, kami dapat mengungkapkan data kepada pihak berwenang sesuai prosedur hukum yang sah.
07

Keamanan Data

Kami menerapkan langkah-langkah keamanan berikut untuk melindungi data Anda:

🔐
Enkripsi PIN

PIN Anda disimpan sebagai hash kriptografi — bukan teks asli. Bahkan pengembang tidak dapat membaca PIN Anda.

🧬
Biometrik via Android Keystore

Data biometrik (sidik jari, wajah) diproses sepenuhnya oleh sistem Android dan hardware perangkat. Aplikasi hanya menerima sinyal "berhasil/gagal" tanpa menyimpan data biometrik apapun.

🔒
HTTPS/TLS

Semua komunikasi jaringan antara aplikasi dan server Supabase dienkripsi menggunakan protokol TLS.

📦
Isolasi Penyimpanan Lokal

Database lokal berada di penyimpanan privat aplikasi (tidak dapat diakses aplikasi lain). Android Backup dinonaktifkan untuk mencegah kebocoran data melalui backup cloud Android.

🗑️
Soft Delete Aman

Transaksi yang dihapus ditandai sebagai is_deleted=true dan disinkronkan ke cloud sebelum dihapus permanen, memastikan konsistensi data.

⚠️ Meskipun kami menerapkan berbagai langkah keamanan, tidak ada sistem yang 100% aman. Kami menyarankan Anda mengaktifkan PIN dan/atau biometrik di aplikasi untuk perlindungan tambahan, serta menjaga kerahasiaan kode undangan usaha Anda.
